# BI.Windows.Shell

Utilidades de shell nativo de Windows para .NET, sin dependencias de WPF.

- `WindowsDarkMode` — tema oscuro para los menús clásicos que dibuja la shell.
- `ShellContextMenu` — el menú contextual real del Explorador (IContextMenu/IContextMenu2).

Requisitos: .NET 8 (`net8.0-windows`), Windows 10 1809+.
